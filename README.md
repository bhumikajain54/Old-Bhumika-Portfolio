# 🚀 Bhumika Jain | Full Stack Web Developer Portfolio

Welcome to my professional portfolio website! This is a modern, responsive, and highly interactive web application built with **React.js** and **GSAP** to showcase my journey, skills, projects, and professional experience.

---

## 🌟 Features

-   **Dynamic Animations**: Powered by **GSAP** and **ScrollTrigger** for smooth, engaging transitions.
-   **Interactive UI**: Smooth horizontal scrolling sliders for Projects, Skills, and Experience.
-   **Typewriter Effect**: An engaging hero section featuring a dynamic typewriter introduction.
-   **Fully Responsive**: Optimized for all screen sizes, from mobile devices to large desktops.
-   **Professional Sections**:
    -   **Home**: Introduction with a 3D-style visual appeal.
    -   **About**: Detailed personal information and overview.
    -   **Experience**: Horizontal timeline of professional roles and contributions.
    -   **Projects**: Showcase of live applications and major coding projects.
    -   **Skills**: Comprehensive list of technical competencies.
    -   **Education & Certifications**: Academic background and specialized training.
    -   **Contact**: Integrated form for direct communication.

---

## 🛠️ Tech Stack

**Frontend:**
-   **React.js**: Library for building the user interface.
-   **CSS3**: Custom styling with a focus on modern aesthetics (glassmorphism, gradients).
-   **GSAP (GreenSock Animation Platform)**: For high-performance web animations.
-   **Vite**: Next-generation frontend tooling for a fast development experience.

**Backend & Tools:**
-   **Formspree**: For handling contact form submissions.
-   **Git/GitHub**: For version control and deployment.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites
-   **Node.js** (v18.0 or higher)
-   **npm** or **yarn**

### Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/bhumikajain54/Old-Bhumika-Portfolio.git
   ```
2. Navigate to the project directory:
   ```sh
   cd BhumikaPortfolio
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Start the development server:
   ```sh
   npm run dev
   ```
