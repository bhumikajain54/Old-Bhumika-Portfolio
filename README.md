# Bhumika Portfolio

This is a React + Vite based portfolio project.

## Project Structure
- `src/components`: UI components (Navbar, Home, About, Project, Skills, etc.)
- `src/assets`: Images and media assets.
- `src/index.css`: Global styles.

## Technologies Used
- React.js
- Vite
- GSAP (for animations)
- CSS3
- HTML5
